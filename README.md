# fasta-toolkit
Этот проект предназначен для работы с fasta-файлами
## Что умеет
Класс Seq хранит последовательность и заголовок, знает длину и определяет алфавит последовательности(нуклеотид/белок).
Класс FastaReader читает FASTA-файл по одной записи, проверяет формат.
## Документация
html-документация собрана через Sphinx. Можно открыть "index.html" в браузере.
## UML-диаграмма
Диаграмма создана на сайте app.diagrams.net, сохранена в одноименном файле в формате .png .
